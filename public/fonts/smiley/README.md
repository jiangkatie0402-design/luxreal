# Aholo Display

Web subset of **Smiley Sans / 得意黑** (Oblique) by atelierAnchor,
<https://github.com/atelier-anchor/smiley-sans>, v2.0.1, licensed under the
SIL Open Font License 1.1 (see `OFL.txt`).

The font is split into unicode-range shards for the web. Because a subset is a
modified version and "Smiley" / "得意黑" are Reserved Font Names, the shards are
renamed **Aholo Display**. Regenerate with `split.py` kept alongside the design
assets if the copy gains new characters (anything missing falls back to MiSans).
