01 — 关于

把真实世界，
带进可计算的空间。

Aholo 空间智能黑客松由 Aholo 发起，面向所有对 3D、AI 与空间计算充满热情的创造者。无论你是开发者、设计师还是研究者，都可以在这里把想法变成可交互的空间体验。

从一段手机视频到一个可漫游、可编辑、可被 Agent 理解的 3D 世界——空间智能正在重写我们与物理世界交互的方式。

07 — FAQ

常见问题

没有找到答案？欢迎发送邮件至 hackathon@aholo3d.cn

谁可以参加？

年满 18 周岁的开发者、设计师、学生与研究者均可报名，不限国籍与专业背景。

需要 3D 或图形学经验吗？

不需要。Aholo 提供开箱即用的 API 与 SDK，赛前 Workshop 会覆盖从采集、重建到 Web 渲染的全流程。

团队规模有什么要求？

每队 1–5 人。个人报名者可在社群内组队，我们也会在开赛前组织组队活动。

参赛是否收费？

完全免费。入围决赛的队伍将获得现场餐饮与住宿支持。

作品知识产权归谁？

作品知识产权归参赛团队所有。主办方仅享有赛事相关的展示与宣传权利。

如何评审？

评审维度包括技术实现（30%）、创新性（30%）、完成度与体验（20%）以及商业与社会价值（20%）。
